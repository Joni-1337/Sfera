# Шаблоны Excel для заданий и тестов

## Исходники банка (загруженные)

Оригинальные файлы лежат в **`source/`**:

| Файл | Категория | Вопросов |
|------|-----------|----------|
| `ege_orthography_50_tasks.xlsx` | Орфография | ~100 |
| `zadanie_9_vowels_100.xlsx` | Задание 9 | 100 |
| `zadanie_14_adverbs_100.xlsx` | Наречия | 100 |
| `zadanie_4_lexics_100.xlsx` | Задание 4 | 100 |
| `zadaniya_7_8_grammar_100.xlsx` | Задания 7–8 | 100 |
| `ege_mixed_variants_10x12.xlsx` | Тесты ЕГЭ | 10 × 12 |
| `advanced_questions_bank.xlsx` | **Шаблон для скачивания** — примеры всех типов вопросов (выбор, пропуск, текст) |

Данные импортированы в **`src/data/question-bank/*.json`** — оттуда их берут кнопки «Готовые» и «Вариант ЕГЭ».

Повторный импорт после правки Excel на рабочем столе:

```bash
npx tsx scripts/import-question-bank.ts
```

## Шаблоны для ручного заполнения

## Как загрузить в приложение

1. Заполните файл (лист **Вопросы**, одна строка = один вопрос).
2. **Задания:** группа → Новое задание → выберите категорию → **Из Excel** → загрузите файл.
3. **Тесты:** Тесты → Новый тест → **Из Excel** → загрузите файл (например `06-ege-test-variant.xlsx`).
4. Опубликуйте, чтобы ученики увидели материал.

Тексты и сложные слова загружаются не через Excel — разделы **Тексты** и **Словарь**.
