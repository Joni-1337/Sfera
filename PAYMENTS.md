# Оплата подписки через ЮKassa

Подписка преподавателя: **1 990 ₽ / 30 дней**. Ученики — бесплатно.

## Пока оформляете самозанятость

Сайт уже готов к оплате. Сейчас можно:

1. **Пользоваться пробным периодом** (3 дня после регистрации)
2. **Держать `SUBSCRIPTION_STUB=true`** в Vercel — кнопка «Оформить» активирует подписку без реальных денег (для тестов)
3. **Задеплоить код оплаты** — когда получите самозанятость, останется только добавить ключи ЮKassa

### Чеклист перед запуском оплаты

- [ ] Страницы для модерации ЮKassa: `/pricing`, `/offer`, `/requisites` (с ИНН)
- [ ] В Vercel: `NEXT_PUBLIC_LEGAL_NAME`, `NEXT_PUBLIC_LEGAL_INN`
- [ ] Код оплаты задеплоен (`git push`)
- [ ] `npx prisma db push` — таблица `SubscriptionPayment` + поля чека и email
- [ ] Самозанятость зарегистрирована
- [ ] Магазин подключён в [yookassa.ru](https://yookassa.ru)
- [ ] `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` в Vercel
- [ ] `SUBSCRIPTION_STUB` убран или `false`
- [ ] Webhook: `https://sferaege.ru/api/payments/yookassa`
- [ ] Тестовая оплата прошла успешно

## Как это работает на сайте

1. Преподаватель заходит на `/pricing` → **«Оформить»**
2. Перенаправление на страницу оплаты ЮKassa
3. После успешной оплаты ЮKassa шлёт webhook на сайт
4. Подписка активируется автоматически на 30 дней (или продлевается, если уже была активна)
5. На email преподавателя приходит письмо **«Подписка оплачена»**
6. Чек покупателю — через приложение «Мой налог»
7. История платежей — в **Настройки → История платежей** (`/settings#payments`)

## Шаг 1. Регистрация в ЮKassa

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru)
2. Подключите магазин (ИП, самозанятый или ООО)
3. В личном кабинете откройте **Настройки → Ключи API**
4. Скопируйте:
   - **shopId** (идентификатор магазина)
   - **Секретный ключ**

Для тестов используйте **тестовый магазин** — деньги не списываются.

---

## Шаг 2. Переменные в Vercel

Vercel → Project → **Settings → Environment Variables**:

| Переменная | Значение |
|------------|----------|
| `YOOKASSA_SHOP_ID` | shopId из ЮKassa |
| `YOOKASSA_SECRET_KEY` | Секретный ключ |
| `APP_URL` | `https://sferaege.ru` |

Когда ЮKassa подключена — **уберите** `SUBSCRIPTION_STUB` или поставьте `false`.

**Redeploy** после изменения переменных.

### Тестовая цена (например 10 ₽)

В Vercel добавьте обе переменные (чтобы совпадали на сайте и в платёжке):

| Переменная | Значение для теста |
|------------|-------------------|
| `SUBSCRIPTION_PRICE_RUB` | `10` |
| `NEXT_PUBLIC_SUBSCRIPTION_PRICE_RUB` | `10` |

Redeploy → оплатите 10 ₽ на `/pricing` → проверьте, что подписка продлилась.

**Вернуть боевую цену:** поменяйте обе на `1990` (или удалите — будет 1990 по умолчанию) → Redeploy.

---

## Шаг 3. Webhook в ЮKassa

В ЮKassa → **Интеграция → HTTP-уведомления**:

**URL уведомлений:**
```
https://sferaege.ru/api/payments/yookassa
```

Включите события:
- `payment.succeeded`
- `payment.canceled`

Сохраните. Без webhook подписка не активируется автоматически.

## Шаг 4. Чеки для самозанятого

**Пункта «Онлайн-касса» в ЮKassa у самозанятого нет — это нормально.** Онлайн-касса нужна ИП и ООО, не вам.

Чеки оформляются в приложении **«Мой налог»**:
1. После поступления оплаты откройте «Мой налог»
2. Зарегистрируйте доход (сумма, например «Подписка СФЕРА»)
3. Отправьте сформированный чек покупателю на email

В Vercel можно добавить `YOOKASSA_SEND_RECEIPTS=false` — сайт не будет передавать данные для онлайн-кассы (для самозанятого они не нужны).

## Шаг 6. Проверка

### Тестовый магазин ЮKassa

1. Войдите как преподаватель на `sferaege.ru`
2. `/pricing` → **Оформить**
3. Оплатите тестовой картой (данные в документации ЮKassa)
4. Вернётесь на `/pricing?payment=return`
5. Подписка должна стать **«Подписка»** в профиле
6. На email — письмо **«Подписка оплачена»**; чек — через «Мой налог»
7. В **Настройки** — запись в истории платежей

### Режим без ЮKassa (заглушка)

Если ключи не заданы, но `SUBSCRIPTION_STUB=true` — кнопка «Оформить» активирует подписку без реальной оплаты (для разработки).

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| «Онлайн-оплата скоро будет доступна» | Добавьте `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` в Vercel |
| Оплатил, подписка не появилась | Проверьте webhook URL в ЮKassa и логи Vercel |
| Нет письма «Подписка оплачена» | Проверьте `RESEND_API_KEY` и `EMAIL_FROM` в Vercel |
| Нет чека на email | Для самозанятого чек оформляется в «Мой налог», не в ЮKassa |
| Ошибка при создании платежа | Проверьте, что магазин активен и ключи верные |
| `db push` ругается на `playing_with_neon` | Добавьте `--accept-data-loss` |
