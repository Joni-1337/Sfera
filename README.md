# СФЕРА

Платформа для преподавателей и учеников: группы, задания, тесты, аналитика и словарь.

Текущий модуль — **СФЕРА.Рус** (подготовка к ЕГЭ по русскому языку).

## Возможности

- **Регистрация преподавателя** — `/register`, 3 дня пробного доступа
- **Вход ученика** — ФИО + ключ доступа (выдаёт преподаватель)
- **Вход преподавателя** — email + пароль с подтверждением email
- **Группы и ученики** — ключи доступа, статистика, архив групп
- **Задания и тесты** — шаблоны ЕГЭ, импорт из Excel, дедлайны
- **Словарь** — сложные слова по темам, импорт, «слово дня»
- **Результаты** — фильтры, экспорт CSV, сворачиваемые карточки
- **Тексты** — библиотека с фильтрами и свои материалы
- **Темы** — тёмная и светлая (настройка преподавателя)

## Быстрый старт

```bash
npm install
npm run db:setup
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

Скопируйте `.env.example` в `.env` и при необходимости настройте `RESEND_API_KEY` для email.

| Команда | Описание |
|---------|----------|
| `npm run dev` | Dev-сервер |
| `npm run db:setup` | База + seed |
| `npm run import:bank` | Импорт банка вариантов ЕГЭ |
| `npm run import:words` | Импорт слов в словарь |

## Стек

- Next.js 15 (App Router)
- TypeScript, Tailwind CSS 4
- Prisma + SQLite
- JWT-сессии (jose), Resend (email)

## Структура

```
src/
  app/           — страницы
  components/    — UI
  lib/           — auth, actions, branding
prisma/          — схема и seed
docs/            — документация проекта (опционально)
```
